# AI Agent Studio 本地一键启动脚本设计

## 目标

在 `/Users/wtf/Desktop/agent-studio/start.sh` 提供一个命令行入口，同时启动 Agent Studio 后端与前端，并在脚本退出时清理本次启动的两个子进程。

## 启动对象

- 后端目录：`Agent-Studio`
- 后端命令：`.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 7100`
- 前端目录：`Agent-Studio-web`
- 前端命令：`pnpm dev`，由项目脚本监听 `4000` 端口

## 启动前检查

脚本启动前依次检查：

1. 两个项目目录存在。
2. 后端虚拟环境中的 Python 可执行文件存在。
3. 后端 `.env` 存在。
4. 系统可以找到 `pnpm`。
5. 前端依赖目录 `node_modules` 存在。
6. `4000` 和 `7100` 端口未被其他进程监听。

任何检查失败时，脚本打印原因和修复命令，并且不启动任何服务。脚本不自动安装依赖、不修改配置、不连接或导入数据库。

## 进程与日志管理

- 前后端作为当前脚本的后台子进程运行，原始输出继续显示在同一个终端。
- 捕获 `INT`、`TERM` 和正常退出信号，仅终止本次脚本创建的进程。
- 任一服务提前退出时，脚本停止另一服务并以非零状态退出。
- 启动后显示前端、后端和 Swagger API 文档地址。

## 验证

1. 使用 `bash -n` 检查脚本语法。
2. 使用隔离的伪命令测试缺少依赖、端口占用、子进程退出和 `Ctrl+C` 清理行为。
3. 在本机真实启动两个服务，分别请求 `http://127.0.0.1:7100/health` 与 `http://127.0.0.1:4000`，随后停止并确认端口释放。

## 非目标

- 不自动打开浏览器。
- 不在后台常驻。
- 不自动安装 Python 或 Node.js 依赖。
- 不修改现有前后端业务代码及配置。
